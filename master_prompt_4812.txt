# PHASE 3 — INVESTIGATE THE EXISTING MODEL'S OUTPUTS

Determine exactly what the current AI model predicts. Do not assume that its outputs are metric measurements.

Inspect the model architecture, inference code, preprocessing, post-processing, and checkpoint metadata.

Answer these questions in `docs/MODEL_OUTPUTS_AND_METRIC_SCALE.md`:

1. Does the model predict relative depth, metric depth, terrain elevation, surface elevation, building height, building masks, or some combination?
2. What are the output tensor dimensions, resolution, data type, units, and numerical range?
3. Are the values normalized between 0 and 1? If so, where and why?
4. Is normalization used only for visualization, or does it alter the actual prediction?
5. Can the current output be converted into metres using a justified calibration method?
6. Which external reference datasets or measurements are required?
7. How are image pixels mapped to geographic coordinates?
8. What coordinate reference system, horizontal units, vertical datum, and elevation reference are used?
9. Does the output preserve geographic alignment when the image is resized, cropped, or tiled?
10. Which outputs are currently used to construct the 3D scene?

Provide representative real output shapes and sample values from the actual model when execution is possible.

Explain the difference between:
- Relative depth: model-dependent relative ordering or depth values.
- Metric depth: distance from the camera, expressed in physical units.
- Ground elevation: elevation relative to a defined vertical datum.
- Surface elevation: elevation of roofs, vegetation, and terrain surfaces.
- Building height: vertical difference between a building surface and its local ground.
- Confidence: a calibrated or otherwise defined measure of prediction reliability.

Never treat a normalized depth value as metres.

If the current model does not support metric reconstruction, document the gap and implement a clearly defined interface for metric calibration or reference-data fusion. Do not claim that a mathematically rescaled relative-depth map automatically becomes physically accurate.
